# Design-of-a-command-processing-system

Проект, который принимает команды по UART от компа, разбирает их и выполняет.

## Как это работает
Прилетает строка вида ADD36 123456789 ABCDEF123 или LED12_8 001 FF. Анализатор её посимвольно щёлкает, узнаёт команду, вытаскивает из неё числа в hex. Обработчик команды дальше смотрит:

если это арифметика (сложить 36+36 или умножить 52×52) - считает;

если это команда к железу (записать в память, включить светодиоды, сбросить маску) - лезет через системную шину STI к нужному исполнителю.

Результат потом генератор сообщений берёт из ПЗУ ("Result ADD36: ..." или "Success LED12_8"), подставляет туда посчитанное число, конвертит в ASCII и шлёт обратно в UART.

Ошиблись с командой - получите "Error command!!!".

## Что внутри
Всё по-честному:

автоматы состояний;

ПЗУ с сообщениями через case;

ОЗУ на 64 байта;

отдельные модули на каждую задачу - UART, анализатор, обработчик, шина, контроллер светодиодов, генератор сообщений.

52-битное умножение сделано «в столбик» за 52 такта, потому что одним тактом такое в железо не влезет.

## Железо
Плата: Tang Nano 20K (27 МГц)

Среда: Gowin EDA

Связь с компом: встроенный USB-UART, 38400 бод, чётность Odd, два стоп-бита

Индикация: результат мигает светодиодами и приходит строкой в терминал

Обращался к плате через терминал picocom (система alt-workstation-11.1-x86_64)
